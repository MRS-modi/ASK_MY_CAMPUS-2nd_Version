# 🎓 Ask My Campus

A modern **Campus Q&A Platform** where students and teachers can ask questions, share knowledge, and resolve academic doubts in one place.

Built as a **full-stack project using FastAPI and JavaScript** with role-based access and an admin management system.

---

# 🚀 Features

### 👨‍🎓 Student Features

* Ask academic questions
* View and answer questions
* Save useful questions
* Receive notifications
* Submit official inquiries

### 👨‍🏫 Teacher Features

* Answer student questions
* Verify correct answers
* Help moderate discussions

### 🛡 Admin Features

* Admin dashboard
* Manage users
* Manage inquiries
* View platform analytics

# ⚙ Installation Guide

### Clone Repository

```
git clone https://github.com/MRS-modi/ASK_MY_CAMPUS-2nd_Version.git
```

### Navigate to Project

```
cd ASK_MY_CAMPUS-2nd_Version
```

### Install Backend Dependencies

```
pip install -r backend/requirements.txt
```

### Run Backend Server

```
uvicorn app.main:app --reload
```

### Run Frontend

Open:

```
frontend/index.html
```
