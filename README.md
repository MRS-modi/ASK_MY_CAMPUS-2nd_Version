# Ask My Campus

Ask My Campus is a college-focused Q&A and inquiry platform where students can ask questions, post answers, receive verified faculty responses, and send private official inquiries.

## Core Features
- User authentication
- Role-based access (Student, Teacher, Admin)
- Ask and answer questions
- Upvote answers
- Verified answers by teachers
- Accepted answers by question owner
- Saved questions
- Private official inquiry system
- Admin management panel

## Tech Stack
- Backend: FastAPI, SQLAlchemy, SQLite
- Frontend: HTML, Tailwind CSS, JavaScript
